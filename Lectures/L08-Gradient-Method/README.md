## Contents

- The (sub)gradient method for convex Lipschitz problems: convergence via the potential function &#8214;x &minus; x<sup>&#8902;</sup>&#8214;<sup>2</sup>
- Step-size selection and the O((LD/&epsilon;)<sup>2</sup>) complexity bound; extension to nondifferentiable functions (subgradient method)
- Constrained problems: the projected gradient method
- Lower complexity bounds for nonsmooth convex optimization (Nemirovski &amp; Yudin): the subgradient method is optimal
- Smooth convex functions: Lipschitz continuous gradients and the quadratic upper bound
- Gradient descent with step size 1/L for smooth convex functions and its O(LD<sup>2</sup>/&epsilon;) complexity
- Strongly convex functions and lower complexity bounds for smooth (strongly) convex optimization
- Nesterov's accelerated gradient method; summary of black-box complexity results
